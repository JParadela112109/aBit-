# aBit

**Build better habits, a bit at a time.**

aBit is a lightweight web app for tiny daily wins — food, movement, and focus — without calorie math or rigid plans. Fill a square, keep the streak, watch your week take shape.

## Stack

- React 19 + TypeScript
- Vite 8

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Product direction

- Brand-first landing with a full-bleed hero
- Interactive weekly habit grid (local prototype)
- Calm, growth-forward visual system (forest ink + citrus lime)

Images currently load from Unsplash for atmosphere; swap for owned photography when ready.
